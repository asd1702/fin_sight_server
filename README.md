# FinSight Server

**금융 뉴스 수집 및 분석 시스템**

FinSight는 한국의 금융 뉴스를 자동으로 수집하고, AI를 활용하여 분석하는 종합적인 데이터 파이프라인 시스템입니다.

## 🎯 주요 기능

- **실시간 뉴스 수집**: 네이버 뉴스 API를 통한 금융 관련 뉴스 자동 수집
- **AI 기반 분석**: OpenAI를 활용한 뉴스 내용 분석 및 카테고리 분류

# FinSight — 서비스 아키텍처 개요

이 문서는 FinSight 시스템의 전체 구조와 핵심 컴포넌트, 데이터 흐름, 운영(로컬/프로덕션) 관점에서의 차이점을 빠르게 이해할 수 있도록 작성되었습니다.
기술적 상세(개발 환경 설정, 코드 기여 방법 등)은 `README.md` 하단 또는 `docs/` 문서로 연결합니다.

대상 독자
- 제품 담당자(PO), SRE/인프라 엔지니어, 데이터 엔지니어, 외부 검토자

요약
- FinSight는 금융 뉴스(주로 네이버) 수집, 기사 전문 수집/전처리, LLM 기반 분석(요약/카테고리/인사이트), 그리고 한국은행 ECOS의 경제지표를 결합해 통계와 인사이트를 생성하는 파이프라인 서비스입니다.

---

## 핵심 컴포넌트 (한눈에)

- 수집(Collectors)
	- 네이버 뉴스 API 기반 키워드 수집
	- 기사 전문 수집(크롤링 / newspaper3k 등)
- 처리(Processors)
	- 텍스트 전처리, 문장 분리, 중복 제거
	- LLM 호출(분석/요약/카테고리 분류)
- 저장 및 모델(Models)
	- PostgreSQL: 기사, 본문, 보강된(Enriched) 분석 결과, 통계 메타데이터
	- SQLAlchemy + Alembic로 스키마 관리
- 외부 데이터 소스
	- 한국은행 ECOS: 경제지표 수집(금리, CPI, GDP 등)
- API & 서비스
	- FastAPI 기반 REST API(조회, 상태, 메트릭 엔드포인트)
- 운영 & 모니터링
	- Prometheus + Grafana, 로그는 기본적으로 stdout으로 집계

---

## 데이터 흐름(시나리오별)

1) 뉴스 기사 수집 및 보강

	 1. 키워드 기반으로 네이버 뉴스 메타데이터 수집
	 2. 기사 URL에서 전문을 크롤링(본문 수집)
	 3. 전처리(불필요 태그 제거, 문장 분리)
	 4. LLM(예: OpenAI)을 호출해 요약/태깅/분류/인사이트 생성
	 5. 결과를 DB에 저장하고 상태(수집/완료/에러 등) 업데이트

2) 경제지표 수집(ECOS)

	 1. ECOS API에서 지표 목록과 시계열 데이터 수집
	 2. 지표별로 정규화 및 저장(카탈로그, 관측치)
	 3. 분석 파이프라인에서 지표를 조합해 통계 뷰 생성

3) 소비(서비스 레이어)

	 - API를 통해 웹/대시보드/레터(뉴스레터) 서비스가 기사 및 통계 데이터에 접근

## 배포/운영 관점

로컬 개발
- `docker-compose.yml`를 사용하면 로컬에서 Postgres, Prometheus, Grafana 등을 포함한 전체 스택을 띄워 개발·디버깅할 수 있습니다.

프로덕션(컨테이너)
- `docker-compose.prod.yml`는 운영 환경에서 애플리케이션을 기동하기 위한 예시 구성입니다.
- 운영에서는 보통 외부(관리형) 데이터베이스(RDS)를 사용합니다. 이 경우 `docker-compose.rds.yml`로 DATABASE_URL을 오버라이드합니다.

자동화된 마이그레이션
- 컨테이너 시작 시 `docker-entrypoint.sh`가 DB 가용성 체크, (옵션)마이그레이션 실행, uvicorn 실행을 담당합니다. CI/CD 파이프라인에서 마이그레이션을 사전에 실행하는 전략도 권장합니다.

안정성 권장사항
- 비밀값(API 키, DB 비밀번호)은 `secrets.env` 또는 클라우드 제공자의 시크릿 매니저에 보관하세요.
- 프로덕션 로그는 중앙집중 로깅 솔루션(예: ELK, CloudWatch)으로 수집하세요.

## 관찰성(Observability)

- 메트릭: Prometheus로 수집, Grafana 대시보드로 시각화
- 로그: 컨테이너 stdout/stderr을 기본으로 수집(추가로 파일 로깅 가능)
- 알람: Prometheus Alertmanager 또는 외부 모니터링 연동 권장
